# 부흥프로젝트 — 강단용 상세 아웃라인 고정 규칙

기준: GitHub 저장소 `udreformed/revival-project`의 확정 제3·4·5회 `detailedOutlineHtml` 실제 형식 (2026-11-17 확인)

## 1. 구성 및 제목
- 상세 아웃라인은 **도입 → 번호를 붙인 본론 대지 → 절정 → 결론**의 순서를 따른다.
- 최상위 제목은 해당 회차의 확정 원고 제목과 같게 하고, 큰 부분 제목은 원고의 소제목을 **글자 그대로** 유지한다.
- 필요에 따라 강단용 아웃라인에 독립된 `절정 — …` 제목을 두어 원고 안의 절정 논증을 분명히 가리킨다. 이는 새 설교 대지를 추가한다는 뜻이 아니다.
- 해당 회차의 본문·중심 주제·대지 순서는 이미 승인된 원고와 일치한다.

## 2. 세부 항목의 고정 문법
- 각 부분은 별도의 `<h2>`와 바로 이어지는 `<ul>`로 표시한다.
- 각 항목은 반드시 `<li><strong>구체적 핵심어</strong> — 근거와 전개를 설명하는 1~3개의 완결 문장.</li>` 형식을 사용한다.
- 예시: `<li><strong>인자의 우주적 크기</strong> — 시 36:5–6에서 인자·신실하심·의로우심·공의를 하늘·산·깊은 바다의 시적 이미지로 선포합니다.</li>`
- `본문 해설`, `적용`, `요약`처럼 포괄적인 명사만 세워 두지 말고 **설교자가 해당 지점에서 무엇을 말해야 하는지** 드러내는 구체적인 핵심어를 사용한다.
- 각 항목에는 가능한 한 **성경 장절, 핵심 논증, 청중을 향한 질문, 다음 단계와 연결되는 논리**를 실제 원고에 맞게 적는다.
- 항목 개수는 필요에 따라 정한다. 숫자를 채우기 위해 반복하거나, 원고에 없는 예화를 만들어 넣지 않는다.

## 3. 주해·원어·복음·적용의 위치
- 본문 주해와 논증은 원고의 진행 순서를 유지한다. 히브리어·헬라어는 설교에서 실제로 설명하는 지점에만 짧게 기록한다.
- 성경 원문의 표현을 설명할 때 원문에서 직접 확인되는 사실과 정경적·목회적 해석을 구분한다.
- 복음은 마지막에 덧붙이는 독립 논평이 아니라 앞 대지에서 제기한 문제의 답으로 연결한다.
- 실례는 **원고에 있는 것만** 기록하며 모든 대지에 의무적으로 배치하지 않는다.
- 참조도서는 원고에 직접 활용되는 논증의 근거가 되지만, 도서 이름·학자를 나열하는 목록이 아웃라인을 대신하지 않는다.

## 4. 원포인트·절정·결론
- 하나의 핵심 질문과 중심주제문을 설교 전체에 관통시킨다.
- 절정은 본문에서 시작한 질문이 그리스도의 복음과 하나님의 영광 안에서 해결되는 지점을 구체적으로 적는다.
- 결론은 새로운 교리를 늘어놓거나 앞 대지를 반복하지 않는다. 본문의 마지막 기도·찬양과 청중의 응답, 특별히 설교 시리즈의 부흥 갈망에 연결한다.
- 부흥은 본문 원뜻에 없는 표현을 강제로 집어넣지 않고 **생명을 주시는 하나님을 향한 신학적·목회적 적용**으로 명시한다.

## 5. 웹 공개 형식 및 검수
- 기존 상세페이지의 `detailedOutlineHtml` 값을 사용한다. `<h2>…</h2>\n<ul>\n<li><strong>…</strong> — …</li>\n</ul>` 구조를 유지한다.
- 별도의 `강단용 상세 아웃라인` 섹션에 노출하고, `원고전체 읽기` 접힘 버튼과 구분한다.
- 간략한 `설교 흐름`(`outline`)과 상세 아웃라인(`detailedOutlineHtml`)은 별개이며, 후자를 3~5개의 한 줄 요약으로 축소하지 않는다.
- 각 대지 소제목, 원문의 직역, 성경 장절, 절정과 결론을 확정 원고와 대조하여 검수한다.
- GitHub 반영은 사용자가 직접 수행한다. **다른 회차의 내용을 변경하지 않는다.**
